## Overview

Aggregation of all Yale’s Public Health Data Science and Data Equity (DSDE) workshops, tutorials, and information sessions, known as Coffee, Cookie, and Coding ($C^3$) Workshops. Find links to their materials, modules adapted for asynchronous learning, and more information about the authors and guest speakers.
